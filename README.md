# NEON REQUIEM

네온 서울을 배경으로 한 싱글 플레이 생존 게임. React와 Canvas 2D로 구현했습니다.

## 실행

Node.js 22 이상. `npm install` 후 `npm run dev`.

Windows에서 npm의 플래그 전달이 실패하면 `node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 4173`으로 실행할 수 있습니다.

## 플레이

- WASD / 방향키: 이동. 전장을 클릭해 목적지로 이동할 수도 있습니다.
- Shift: 짧은 무적 회피. Space: 충전된 오버클럭 광역 공격.
- Esc: 일시정지 / 재개. 다른 창으로 이동하면 자동으로 일시정지합니다.
- 모바일: 좌측 조이스틱으로 이동하고 우측 버튼으로 스킬 사용.
- 자동 사격으로 적을 처치하고 데이터 조각을 회수하면 레벨업합니다. 3가지 강화 중 하나를 선택합니다.
- 중계기 원 안에 8초 머무르면 해킹됩니다. 원을 벗어나도 진행도가 보존됩니다.
- 중계기 3개를 연결하면 다음 구역으로 이동합니다. 세 번째 구역까지 연결하면 승리합니다.
- 최고 처치 수와 최장 생존 시간은 브라우저 localStorage에 저장됩니다.

## 구성

- `src/game.js`: 이동, 자동 조준/탄환, 적 웨이브, 경험치, 강화, 목표, 렌더링.
- `src/App.jsx`: 메뉴, HUD, 입력, 모달, 기록, 선택 가능한 저음 앰비언트 사운드.
- `src/theme.css`: 데스크톱 / 모바일 UI.
- `public/assets`: 독립 생성한 전장 3개와 투명 캐릭터·적·라이플 이미지.
- `tests/game.test.mjs`: 시간 기반 이동, 일시정지, 쿨다운, 강화, 목표, 승패 검증.

`node --test tests/game.test.mjs`로 게임 로직을 검사하고 `npm run build`로 정적 빌드를 생성합니다. 결과는 `dist/client`에 있습니다. Sites 호스팅용 기존 런타임도 보존돼 있습니다.

## 범위

로컬에서 실행하는 첫 플레이 가능 버전입니다. 캐릭터는 투명 래스터 스프라이트이며 완전한 3D 모델이나 프레임별 애니메이션은 아닙니다. 지도 가장자리 건물은 배경 장식이고 개별 건물 충돌은 구현하지 않았습니다. 별도 계정, 서버, 온라인 랭킹은 없습니다. 기본 음향은 단순 합성 앰비언트입니다.
