# NEON REQUIEM

네온 서울을 배경으로 한 싱글 플레이 생존 게임. React와 Canvas 2D로 구현했습니다.

## 실행

Node.js 22 이상. `npm install` 후 `npm run dev`.

Windows에서 npm의 플래그 전달이 실패하면 `node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 4173`으로 실행할 수 있습니다.

## 플레이

- WASD / 좌측 조이스틱: 이동.
- Shift: 짧은 무적 회피. Space: 충전된 오버클럭 광역 공격.
- Esc: 일시정지 / 재개. 다른 창으로 이동하면 자동으로 일시정지합니다.
- 모바일: 좌측 조이스틱으로 이동하고 우측 버튼으로 스킬 사용.
- 정확히 하나의 무작위 무기로 시작합니다. 라이플도 무작위 무기 풀에 포함되며 항상 지급되지 않습니다.
- 적을 처치하고 데이터 조각을 회수하면 레벨업합니다. 3개 카드에서 **새 무기 장착** 또는 **보유 무기 강화**를 선택합니다. 둘 다 가능한 경우 두 종류가 함께 나오며, 장착한 무기는 모두 동시에 자동 공격합니다.
- 모노와이어는 근접 원형 베기, EMP 노바는 주변 피해·적 정지·적 탄환 제거, 중력 우물은 흡인·지속 피해, 궤도 강습은 무작위 위치 폭격입니다. 강습은 20% 확률로 피해 2.5배·범위 1.4배의 강화 폭발이 발생합니다. 기존 라이플·드론·아크 연쇄 전격도 함께 장착할 수 있습니다.
- 무기 강화는 해당 무기의 피해와 공격 주기를 개선합니다. 범위·발사 수·주기 개선에는 한도가 있고 이후에도 피해 강화는 계속됩니다. 일시정지 화면에서 보유 무기와 레벨을 확인합니다. 단독 체력 회복·능력치 카드는 무기 선택으로 대체됐으며 중계기/구역 완료 회복은 유지됩니다.
- 중계기 타원 안에 누적 8초 머무르면 해킹됩니다. 밖으로 나가도 진행도가 보존됩니다.
- 중계기 3개를 연결하면 다음 구역으로 이동합니다. 세 번째 구역은 연결 후 등장하는 집행관 NULL WARDEN을 처치해야 승리합니다.
- 돌진형은 주황 경로, 사격형은 보라 조준선, 자폭형은 연두 폭발 범위를 예고합니다. 예고를 보고 피하거나 자폭 전에 적을 처치하세요.
- 집행관은 탄막과 위치 지정 폭발을 번갈아 사용하며 체력 50% 이하에서 과부하에 진입합니다.
- 음향 버튼으로 사격·피격·처치·해킹·경고 효과음을 켭니다. 기본값은 음소거입니다.
- 최고 처치 수와 최장 생존 시간은 브라우저 localStorage에 저장됩니다.

## 구성

- `src/game.js`: 이동, 자동 조준/탄환, 적 웨이브, 경험치, 강화, 목표, 렌더링.
- `src/App.jsx`: 메뉴, HUD, 입력, 모달, 기록, 음향 제어.
- `src/combat.js`: 적 패턴, 보스 공격, 적 탄환, 공격 예고, 공통 해킹 반경.
- `src/weapons.js`: 무기 데이터, 무작위 시작·3개 선택지, 다중 무기 공격·범위 효과·강화 수치.
- `src/audio.js`: 음소거·동시 발음 제한을 적용한 Web Audio 전투 효과음.
- `src/theme.css`: 데스크톱 / 모바일 UI.
- `public/assets`: 독립 생성한 전장 3개와 투명 캐릭터·적·라이플 이미지.
- `tests/game.test.mjs`: 시간 기반 이동, 일시정지, 쿨다운, 강화, 목표, 승패 검증.

`node --test tests/game.test.mjs tests/movement.test.mjs tests/combat.test.mjs tests/weapons.test.mjs tests/audio.test.mjs`로 게임 로직을 검사합니다. `npm run build` 완료 후 `npm run test:sites`를 실행합니다. 결과는 `dist/client`에 있습니다. Sites 호스팅용 기존 런타임도 보존돼 있습니다.

개발 서버의 `/tests/combat-preview.html?scene=boss`는 실제 App과 렌더러를 사용하는 정지 화면 검증용 픽스처입니다. `scene=blast`와 `scene=patterns`도 지원합니다. 배포 빌드에는 포함되지 않습니다.

무기 검증용 `scene=choices`(장착/강화 선택), `scene=loadout`(보유 목록), `scene=weapons`(동시 공격), `scene=orbital`(강화 폭발)도 지원합니다.

## 범위

로컬에서 실행하는 첫 플레이 가능 버전입니다. 캐릭터는 4프레임 보행 스프라이트이며 완전한 3D 모델은 아닙니다. 돌진·사격·자폭·보스는 각각 고유한 4프레임 스프라이트로 구분합니다. 지도 가장자리 건물은 배경 장식이고 개별 건물 충돌은 구현하지 않았습니다. 별도 계정, 서버, 온라인 랭킹은 없습니다. 음향은 Kenney CC0 파일 기반 효과음이며([출처·라이선스](AUDIO-CREDITS.md)), 장시간 난이도 조정과 실제 모바일 기기 청취 검증은 후속 작업입니다.

선택 시안: `exec-bb3a9c27-809c-4b8e-a96c-948774059424.png` (첫 번째 표시된 BLACK RAIN DISTRICT 이미지).

무기 아이콘과 레벨은 체력·경험치 바로 아래에 표시됩니다. 레벨업 3개 선택지에 회피·오버클럭 강화가 포함되며 두 능력은 LV.6까지 성장합니다. 능력 수치는 강화 카드와 일시정지 화면에서 확인합니다.
