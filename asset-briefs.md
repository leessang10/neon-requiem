# Asset production

All raster assets were created with the built-in image generation tool and copied into `public/assets`. The selected concept was used as visual reference; no Warhammer source assets were copied.

| File | Generation brief |
| --- | --- |
| battlefield.png | Empty overhead rain-soaked Seoul intersection, cyan/magenta wet reflections, industrial photorealistic game art, clear traversable center, architecture and steam at edges; no actors, vehicles, UI, bullets or pickups. |
| terminal.png | Empty overhead elevated maglev terminal plaza, wet platform, cyan/magenta glow and orange safety markings; architecture at outer edges and unobstructed traversal center. |
| arcology.png | Empty overhead corporate rooftop plaza, wet concrete, gold repair seams, cyan perimeter glow and red emergency lights, futuristic towers at outer edges. |
| runner.png | Single full-body black-armored cyberpunk mercenary, cyan visor, upper-right smart rifle, realistic three-quarter game sprite, boots visible, genuinely transparent background. |
| enemy.png | Single compact black corporate security robot, red central optic, chunky mechanical limbs, realistic armor, top-down three-quarter game sprite, transparent background. |
| rifle.png | Decorative fictional smart rifle game inventory icon, cyan holographic side view, centered 3:1, transparent background, no technical construction details, text or border. |

UI icons: Phosphor React. Fonts: Rajdhani, Barlow Condensed, Noto Sans KR through Google Fonts, with local sans-serif fallbacks.
